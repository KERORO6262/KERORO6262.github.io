FVTT MOD：DND5E NPC生成器

FoundryVTTJavaScriptMODDND5E

一個 FoundryVTT 模組，可快速生成帶有名字、背景、個性、怪癖、外觀、年齡與裝備的 D&D 5e NPC。

  • 在聊天框輸入 /npc 就能生成，也可以依序指定種族、類型與性別
  • 年齡依各種族的壽命分布抽選，外貌組合體型、髮色、瞳色與種族特徵
  • 裝備與法術依 NPC 類型從 JSON 檔載入
  • 支援 FoundryVTT v13.351 與 dnd5e 5.3.0
設計取捨

NPC 資料全部放在外部的 TXT 與 JSON 檔，不會寫程式的 GM 也能修改或擴充；代價是這些檔案的內容與格式要靠使用者自己維護。

更新說明

目前以 GitHub 為主要發佈管道，歡迎提交 Issue 或 PR。

Unit Power Scorer 40K

Web ToolJavaScriptWarhammer 40K

戰鎚 40K 單位戰力計算工具。專為桌遊玩家設計的網頁應用，可快速計算與評估單位強度分數。

  • 輸入單位屬性、多組武器與領袖、光環加成
  • 加總整支軍隊的點數，以及攻擊、防禦與戰術權重
  • 支援 1000、2000、3000 分三種對戰規模
  • 軍隊資料可用 JSON 匯入與匯出
設計取捨

屬性、武器與加成都拆成獨立欄位，能組合出各種規則情境；代價是建立一個單位要填比較多欄。

更新說明

依據遊戲版本持續維護資料表，目前穩定運行中。

WAROGAN PDF Model Parser

Web ToolJavaScriptWarhammer 40KPDF Parser

將 WAROGAN 匯出的戰鎚 40K 名冊 PDF 解析為可搜尋的結構化資料。完全在瀏覽器端執行，免安裝、免帳號。

  • 可切換群組與個別兩種檢視
  • 跨模型名稱、裝備、能力與關鍵字搜尋
  • 匯出 JSON、CSV、獨立 HTML，或直接複製表格
  • 目前限制：掃描版、沒有文字層的 PDF 無法解析
設計取捨

能力、關鍵字與裝備用規則比對，不建資料庫，工具因此不含任何官方資料；代價是 WAROGAN 匯出格式改變時要更新規則，歸屬不確定的項目會標示警告，請使用者確認。

更新說明

持續修復 PDF 解析相容性問題，改善跨版本名冊的識別準確率。
